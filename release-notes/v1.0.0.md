编程小星球（CodeSpark）首个公开版本，面向家庭 Android TV 的亲子编程应用。

## 内容

- 36 个任务、72 个探索/挑战配置，分为顺序花园、发现小侦探、重复游乐场、如果森林、小帮手工坊、我的创作星球六个主题。
- 重复卡（2–4 次，整段重复）、条件卡（有花时 / 没有花时）、小帮手动作包与地图创作。
- 三个档案：小芽（探索）、小星（挑战）、一起玩（合作），各自保存进度和六张创作地图。
- 普通方向键遥控器即可操作，中文语音与课程全部内置，无需联网。

## 安装

- 下载 `CodeSpark.apk`（与 `codespark-tv-1.0.0-release.apk` 为同一文件），通过 U 盘、局域网传输或 `adb install -r` 侧载到 Android 6.0 及以上的 Android TV / 电视盒子。
- 已在 Android TV API 34 模拟器（1080p）完成完整课程测试，各品牌真机未逐一验证。界面与语音为简体中文。
